phoneviewcomposer - Privacy Policy

Last updated: September 30, 2026

phoneviewcomposer is a Chrome extension that shows a phone preview next to the Gmail compose window. It does not collect, store, transmit, or share any personal data. The developer operates no server and receives nothing from the extension.

What we collect

Nothing. The extension has no accounts, no analytics, no tracking, no ads, and no third-party code. It contains no crash or usage reporting.

What the extension reads

The extension runs only on mail.google.com. To draw the preview, it reads the following from the page in your browser:

  • The subject, recipients, and body of the compose window that is open.
  • The name and email address of the signed-in Google account, as Gmail shows them on the page, to display as the sender in the preview.

This information is used only to draw the preview on the same page. It is not saved, and it is not sent anywhere.

Network requests

The extension makes no network requests of its own. If your draft contains an image, your browser loads that image for the preview from the same address that Gmail already uses to show it in the compose window.

Data stored in your browser

The extension stores one setting in your browser's local storage for Gmail: whether you closed the phone preview. It stores no message content. You can remove the setting by clearing site data for mail.google.com or by uninstalling the extension.

Permissions

The extension asks for access to https://mail.google.com/* only. It uses this access to run on Gmail and draw the preview. It requests no other permissions.

Children

phoneviewcomposer is not directed at children and collects no data from anyone.

Changes

If this policy changes, the revised version will be posted on this page with a new date.
