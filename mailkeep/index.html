MailKeep

Every mailbox on your account, in one place.

MailKeep is a mail client for people who run several addresses across their own domains. Give it your mail account's API key once and it finds every mailbox you have, so you never set up another account by hand. Each mailbox gets its own inbox, and a reply always goes out from the address it arrived at.

Getting started

  • Tap No account yet? Look around a sample inbox on the first screen to try the app without an account. The sample data is fabricated and nothing is sent or fetched.
  • To use your own mail, enter your account email and an API key from your mail host's admin panel, then tap Connect.
  • Tap Connect on a mailbox to start reading it. MailKeep asks your mail host for an application-specific credential for that mailbox. Your mailbox password is not changed, so other mail apps keep working.

Help

  • A mailbox can be read but not send yet. A newly connected mailbox becomes readable straight away; sending switches on a few minutes later. The mailbox shows a warning icon until it does.
  • Switching folders. The strip above the message list moves between Inbox, Drafts, Sent, Archive, Junk and Trash.
  • Sent mail. Anything you send is filed into Sent as the same message that was delivered, so replies thread correctly.
  • New mail alerts are generated on your device. Because there is no server, checking happens when iOS allows it rather than instantly. Refresh now in the account menu checks immediately.
